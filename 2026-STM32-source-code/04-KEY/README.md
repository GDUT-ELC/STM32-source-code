# 04-KEY：按键扫描工程

## 工程说明

使用 STM32F407VET6 扫描四个低电平有效按键，通过软件延时消抖，并在 OLED 上显示最近一次按下的按键编号。

## 使用方法

1. K1、K2、K3、K4 分别连接 PD0、PD1、PD3、PD4，按下时接地；输入使用上拉。
2. 连接 SPI OLED：SCK/MOSI/RES/DC/CS 分别为 PE9/PE10/PE11/PE12/PE13。
3. 用 Keil MDK 打开 `MDK-ARM/4-KEY.uvprojx`，编译、下载。按下并松开按键，OLED 显示对应的 `Key 1 press` 至 `Key 4 press`。
4. 在主循环调用 `key_getnum()`，返回 1–4 表示对应按键事件，0 表示没有事件。

## 使用注意

- 当前实现会延时 20ms、等待松手、再延时 20ms，因此按住按键会阻塞主循环，松开后才返回编号。
- 同时按多个键时按 K1→K4 的判断顺序处理，不支持组合键或长按重复触发。
- 不要在中断中调用此扫描函数；需要持续采集、通信或实时控制时，应改用不阻塞的消抖方式，可参考综合工程。
- 改用高电平有效按键时，需要同时修改 GPIO 上下拉和判断逻辑。
