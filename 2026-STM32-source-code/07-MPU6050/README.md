# 07-MPU6050：六轴传感器数据读取工程

## 工程说明

使用 STM32F407VET6 通过软件 I²C 读取 MPU6050 的三轴加速度和三轴角速度原始数据，并在 OLED 左、右两列分别显示。主循环读取后延时 20ms；本独立工程展示原始计数，姿态角演示见 11-Demo。

## 使用方法

1. MPU6050 的 SCL 接 PA4、SDA 接 PA5，按模块要求供电并共地；总线应上拉至 3.3V。当前 7 位地址为 `0x68`，模块 AD0 应为低电平。
2. 连接 OLED：SCK/MOSI/RES/DC/CS 分别接 PE9/PE10/PE11/PE12/PE13。
3. 用 Keil MDK 打开 `MDK-ARM/7-MPU6050.uvprojx`，编译、下载。正常显示 `MPU6050 TEST`，转动模块观察 AX/AY/AZ、GX/GY/GZ 的变化。
4. GPIO 初始化后先调用 `MPU6050_Init()`，成功后再调用 `MPU6050_GetData()`，并检查返回状态。

## 使用注意

- 当前量程为加速度 ±16g、角速度 ±2000°/s，换算约为 `加速度计数 / 2048` g、`陀螺仪计数 / 16.4` °/s；修改量程后必须同步修改换算系数。
- 原始加速度包含重力，陀螺仪有零偏；需要姿态计算时先做静止校准，并确认模块安装方向和轴向。
- AD0 为高时地址变为 `0x69`，需修改 `Bsp/MPU6050.h` 中的地址宏；WHO_AM_I 检查值仍为 `0x68`。
- 出现 `MPU6050 ERROR` 或 `CHECK I2C` 时，检查地址、供电、共地及上拉。本示例初始化失败后需排除故障并复位重试。
- 软件 I²C 延时与 CPU 时钟、编译优化有关，移植时需确认开漏 GPIO 配置和实际总线时序。
