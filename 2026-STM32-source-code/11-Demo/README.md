# 11-Demo：综合外设演示工程

## 工程说明

将 01–10 和 12 号工程的功能集成到同一份 STM32F407VET6 固件，通过 OLED 的 11 个测试页验证彩灯、蜂鸣器、显示、按键、电机、ADC、MPU6050、超声波、串口、WiFi/MQTT 和外部 Flash。

## 使用方法

1. 用 Keil MDK 打开 `MDK-ARM/11-Demo.uvprojx`，先按下表核对实际接线和供电。
2. 在 `Bsp/demo_config.h` 修改电机演示目标、WiFi/MQTT 参数及 Flash 测试地址。**当前 A/B 电机目标均为 99000 CPS，首次使用前应改为适合实际电机的低速目标。** 编码器和 PID 参数在 `Bsp/motor_config.h`。
3. 编译、下载并运行。上电时电机保持停止；OLED 初始进入彩灯页。传感器和串口在后台工作。
4. 使用 K1 下一页、K2 上一页、K3 执行当前页操作、K4 停止电机并关闭灯光、蜂鸣器和距离报警；翻页也会停止电机及关闭上一页输出。

| 模块 | STM32 接线 / 资源 |
| --- | --- |
| WS2812 DIN | PB8，TIM10_CH1 |
| 无源蜂鸣器 | PE14，TIM1_CH4 |
| OLED SCK / MOSI / RES / DC / CS | PE9 / PE10 / PE11 / PE12 / PE13，软件 SPI |
| K1 / K2 / K3 / K4 | PD0 / PD1 / PD3 / PD4，低电平有效 |
| 电机 AIN1 / AIN2、BIN1 / BIN2 | PD11 / PD10、PD8 / PD9，DRV8848 |
| A / B 编码器两相 | PD12 / PD13（TIM4）、PC6 / PC7（TIM3） |
| ADC 光敏输入 | PB0，ADC1_IN8 |
| MPU6050 SCL / SDA | PA4 / PA5，软件 I²C，7 位地址 0x68 |
| HC-SR04 TRIG / ECHO | PA6 / PA7，EXTI + TIM5 测时 |
| UART4 TX / RX | PA0 / PA1，115200、8N1 |
| USART2 TX / RX | PA2 / PA3，115200、8N1 |
| ESP8266 UART5 TX / RX | PC12 / PD2，115200、8N1 |
| Flash SCK / MISO / MOSI / CS | PB3 / PB4 / PB5 / PA15，SPI1 |
| 下载调试 SWDIO / SWCLK | PA13 / PA14 |

串口 TX 接外部设备 RX，RX 接对方 TX，并共地。OLED、传感器和串口使用匹配的 3.3V 逻辑；HC-SR04 的 ECHO 电平按实际模块处理。

| 测试页 | 观察内容 | K3 操作 |
| --- | --- | --- |
| 01 彩灯 | 红绿蓝渐亮 | 暂停并熄灭 / 继续 |
| 02 蜂鸣器 | 响 1 秒、停 1 秒 | 静音 / 继续 |
| 03 OLED | 字符及数字显示 | 切换中文测试 |
| 04 按键 | 最近按键和累计次数 | 清空次数 |
| 05 电机 | A/B 速度 CPS、PWM 千分比 | 正向闭环→反向闭环→开环→停止 |
| 06 ADC | PB0 原始值、毫伏数 | 无 |
| 07 MPU6050 | 角度、加速度或角速度 | 角度→加速度→角速度；故障时重试初始化 |
| 08 超声波 | 距离、回波宽度、无回波提示 | 开关小于 10cm 的蜂鸣报警 |
| 09 UART | 两路收发计数、错误及最近数据 | 两个串口各发送测试文本 |
| 10 ESP8266 | AT、WiFi、MQTT 阶段和结果 | 重新开始测试或联网 |
| 12 Flash | JEDEC ID、读写校验结果 | 再执行一次读写测试 |

09 页使用 UART4 和 USART2，均可通过串口助手发送数据并接收同一通道的回显；静默 5ms 分包，单包最多 128 字节。UART5 专用于 ESP8266。

10 页联网参数在 `Bsp/demo_config.h`：WiFi 名称为空时仅验证 AT 回包；填写 WiFi 参数后测试热点连接；再填写 MQTT 客户端、认证信息、服务器与端口后测试 MQTT。需要支持对应 MQTT 指令的 ESP8266 AT 固件。

## 使用注意

- **电机参数不能直接照搬。** 首先确认减速比、编码器单相脉冲数、四倍频定义和输出轴每圈计数；在 `motor_config.h` 填写两路 `COUNTS_PER_REV` 后才能正确换算 RPM，当前两路均为 0。当前闭环演示目标为 ±99000 CPS，开环演示为 A=+300‰、B=-300‰，应在实际测试前调整。
- 初次电机调试架空轮子、逐路低速测试，确认正向输出对应正向编码器反馈，再分别整定 PID，检查驱动电源、编码器电平、限流与温升。本工程电机 PWM 为 10kHz，05 独立工程为 1kHz，调参效果可能不同。
- 本板 DRV8848 的模式与上电输入有关；优先让 MCU 先运行再开启 VM，并检查 A/B 是否独立响应。长时间断点暂停会影响测速和控制，不应据此判断闭环性能。
- MPU6050 上电后保持静止，程序需要至少 64 组稳定数据、持续至少 1 秒完成陀螺仪零偏校准，实际可能等待数秒。角度视图按 K4 将当前相对航向归零，同时执行停止输出。
- `YawRel` 是相对航向，会漂移，不能作为正北方位；动态加速度和安装方向会影响角度。加速度单位为 g，角速度为 °/s，量程分别为 ±16g、±2000°/s。
- 超声波每次触发至少间隔 60ms，35ms 未完成时报告无回波；这里使用 PA7 外部中断测脉宽，以避开 TIM3 被电机编码器占用的冲突。移植时不能直接叠加各独立工程的定时器配置。
- **上电会在 Flash 的 0x001000 写入 `11 22 33 44` 并读回比较。** 将 0x001000–0x001FFF 整个扇区预留给测试；12 页 K3 重试会交替写测试数据及反码，不能用于存放重要参数。
- Flash 应为 GD25Q80C，期望 ID 为 `0xC84014`。擦写不是掉电原子操作；不要在中断或多个任务中同时调用驱动。综合工程的 Flash 驱动允许 QE=1 时使用普通 SPI 指令，与 12 独立工程当前的 QE 检查行为有区别。
- 没接 MPU6050、ESP8266 或 Flash 时，可继续测试其他页面；先检查实际硬件和对应页错误提示，再重试。AT、WiFi、MQTT 的 PASS 以接收到相应成功回包为依据。
- 重新生成 CubeMX 代码后，需检查自定义 HAL 回调、GPIO PWM、PA7 EXTI、TIM1/TIM10 时钟及 Bsp 文件引用是否保留。
