# 08-HCSR04：超声波测距工程

## 工程说明

使用 STM32F407VET6 触发 HC-SR04，通过 TIM3_CH2 输入捕获测量 ECHO 高电平宽度，换算距离并在 OLED 上显示，距离单位为厘米。

## 使用方法

1. TRIG 接 PA6，ECHO 经合适电平转换后接 PA7（TIM3_CH2）；按模块规格供电并共地。
2. OLED 的 SCK/MOSI/RES/DC/CS 分别接 PE9/PE10/PE11/PE12/PE13。
3. 用 Keil MDK 打开 `MDK-ARM/8-HCSR04.uvprojx`，编译、下载后，将平整物体置于探头前观察距离。
4. 保留 TIM3 基本计时及通道 2 捕获中断的启动和回调。调用 `hcsr04_start()` 触发测量，待回波捕获后通过 `hcsr04_getdistance(&HCSR04)` 读取最近结果。

## 使用注意

- 常见 HC-SR04 使用 5V 供电，ECHO 也可能输出 5V，接 MCU 前应确认电平兼容；不同模块的供电及触发门限按其规格处理。
- 当前 TIM3 为 1MHz 计数，即每计数 1μs；距离按固定声速 348m/s 换算。更改时钟、预分频或环境温度时，需要检查距离换算。
- 主循环当前延时 50ms；实际使用建议将测量间隔设为至少 60ms，并等待上一轮回波结束，避免重复触发干扰。
- 代码将小于 2cm 的显示值置为 2cm，因此显示 2cm 不代表测量一定有效。过近、斜面、软质吸声物体或无回波时结果可能不可靠。
- 当前独立驱动没有完整的无回波超时恢复，可能保留旧距离。用于实际控制时应增加有效性及超时判断；11-Demo 提供了另一种带超时处理的测量方式。
