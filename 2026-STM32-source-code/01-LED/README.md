# 01-LED：WS2812 彩灯工程

## 工程说明

使用 STM32F407VET6 的 TIM10_CH1 驱动一颗 WS2812 RGB 灯珠，循环演示红、绿、蓝三种颜色从暗到亮。每次亮度增加后延时约 50ms。

## 使用方法

1. 将 WS2812 的 DIN 接 PB8，按灯珠规格供电，并与开发板共地。
2. 用 Keil MDK 打开 `MDK-ARM/1-LED.uvprojx`，编译、下载并运行，即可观察颜色和亮度变化。
3. 修改 `Core/Src/main.c` 中的演示；`WS_SetGRBColor(r, g, b)` 设置颜色，`WS_SetBrightnessColor(r, g, b, brightness)` 同时设置亮度，各参数范围均为 0–255。

## 使用注意

- 这是 WS2812 单总线灯珠工程，接线时区分 DIN 与 DOUT；当前接口一次只发送一颗灯的数据。
- 当前按 8MHz 外部晶振、168MHz 系统时钟配置，TIM10 周期为 210 个计数，对应约 800kHz。修改时钟、定时器或编译优化后，需要重新确认灯珠时序。
- 驱动通过轮询定时器发送数据，中断延迟可能影响波形；移植到复杂程序时应实测，灯珠数量增加时也需调整发送方式。
- 外接灯珠时确认供电能力及 DIN 高电平门限，避免由 GPIO 直接给灯珠供电。
