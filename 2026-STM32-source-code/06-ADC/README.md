# 06-ADC：光敏电阻与电压采集工程

## 工程说明

使用 STM32F407VET6 的 ADC1_IN8 对 PB0 进行 12 位单次采样，读取光敏电阻分压值，并在 OLED 上显示原始 ADC 值和换算电压，约每 50ms 更新一次。

## 使用方法

1. 将光敏电阻分压输出或待测模拟信号接 PB0，与开发板共地；OLED 的 SCK/MOSI/RES/DC/CS 分别接 PE9/PE10/PE11/PE12/PE13。
2. 用 Keil MDK 打开 `MDK-ARM/6-ADC.uvprojx`，编译、下载后改变光照或输入电压，观察读数。
3. 初始化 ADC1 后调用 `adc_read_value()` 获取原始值，再用 `adc_convert_to_voltage()` 换算为伏特。

## 使用注意

- 原始值范围为 0–4095，当前换算为 `原始值 / 4095 × 3.3V`；实际参考电压变化时，应修改 `Bsp/adc_driver.c` 中的参考电压或做校准。
- 输入信号应保持在 GND 到实际 ADC 参考电压范围内，不能直接接 5V 或电机电源；更高电压需先分压或调理。
- 当前采样通道是 PB0，不是初始化代码中同时出现的 PA2。更换通道时要同步修改 ADC 通道与 GPIO 模式。
- 光敏电阻读数表示分压结果，不直接等于照度；光照变强时读数升降取决于分压接法。采样超时也可能返回 0，排查时不能仅据此判断为零电压。
