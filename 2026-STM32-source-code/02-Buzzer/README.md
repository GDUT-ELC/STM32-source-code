# 02-Buzzer：PWM 蜂鸣器工程

## 工程说明

使用 STM32F407VET6 的 TIM1_CH4 在 PE14 输出 PWM，驱动无源蜂鸣器，循环鸣叫 1 秒、停止 1 秒。当前音调约 2.73kHz，占空比约 50%。

## 使用方法

1. 按开发板原理图连接 PE14 对应的蜂鸣器驱动电路，确认供电和共地。
2. 用 Keil MDK 打开 `MDK-ARM/2-Buzzer.uvprojx`，编译、下载并运行。
3. 在 `Core/Src/main.c` 调整鸣叫间隔；初始化 TIM1 后调用 `buzzer_on()` 鸣叫，调用 `buzzer_off()` 停止。

## 使用注意

- 本工程按无源蜂鸣器设计；更换有源蜂鸣器时，需要按模块触发电平和驱动方式调整代码。
- 当前 TIM1 时钟为 168MHz，PSC=83、ARR=731，频率为 `168MHz / 84 / 732`。改变音调时还需调整 `Bsp/buzzer.c` 的比较值，确保比较值不超过周期。
- 蜂鸣器的额定电压、电流应与驱动电路匹配；需要较大电流的蜂鸣器应通过三极管等电路驱动。
